### Task 2: H1 + minimax / alpha-beta

**Files:**
- Create: `ai_minimax.py`

**Interfaces:**
- Consumes: `Board`, `RED`, `YELLOW`, `ROWS`, `COLS` จาก `game.py`
- Produces (`ai_minimax.py`):
  - `WIN_SCORE = 1_000_000`
  - `class Result(NamedTuple)`: `move: int | None`, `score: int`, `nodes: int`, `depth: int`
  - `h1(board: Board, player: int) -> int`
  - `search(board: Board, depth: int, alphabeta: bool = True, heuristic=h1) -> Result`

ค่าที่กำหนดไว้ (spec ส่วน Heuristic H1):
- คิดคะแนนจากทุกหน้าต่างยาว 4 ช่อง (ทั้งหมด 69 หน้าต่าง)
  - ของเรา 3 ตัว + ว่าง 1 ช่อง = **+5**
  - ของเรา 2 ตัว + ว่าง 2 ช่อง = **+2**
  - ของคู่แข่ง 3 ตัว + ว่าง 1 ช่อง = **−4**
- หมากของเราในคอลัมน์ 3 ได้ **+3** ต่อหนึ่งตัว

กติกาของ search (negamax) คิดคะแนนจากมุมของ `board.turn` เสมอ:
- นับ node ทุกครั้งที่เรียกฟังก์ชันวนซ้ำ (รวม root)
- ตรวจตามลำดับนี้:
  1. ถ้า `last_move_won()` ให้คืน `-(WIN_SCORE + depth_left)` (แพ้เร็วกว่าแย่กว่า)
  2. ถ้า `is_full()` ให้คืน `0`
  3. ถ้า `depth_left == 0` ให้คืน `heuristic(board, board.turn)`
- วนลูกตาม `valid_moves()` และเปลี่ยน best move ก็ต่อเมื่อคะแนนมากกว่า (`>`) อย่างเดียว เมื่อคะแนนเท่ากันจะได้ช่องที่อยู่ใกล้กลางกว่า
- ห่อ `drop` / `undo` ด้วย `try/finally`
- ถ้า root เป็นกระดานที่จบเกมแล้ว ให้คืน `move=None`

```python
def _self_check():
    assert h1(Board.from_moves(""), RED) == 0
    assert h1(Board.from_moves("3"), RED) == 3
    assert h1(Board.from_moves("3"), YELLOW) == 0

    for d in (1, 2, 3, 4):
        assert search(Board.from_moves("001122"), d).move == 3   # ชนะทันที
    for d in (2, 4):
        assert search(Board.from_moves("00112"), d).move == 3    # ต้องกัน

    assert search(Board.from_moves(""), 1, alphabeta=False).nodes == 8
    assert search(Board.from_moves(""), 2, alphabeta=False).nodes == 57

    for pos in ("", "33", "3243", "001122", "0213465"):
        for d in (1, 2, 3, 4):
            mm = search(Board.from_moves(pos), d, alphabeta=False)
            ab = search(Board.from_moves(pos), d, alphabeta=True)
            assert (mm.move, mm.score) == (ab.move, ab.score), (pos, d)
    assert search(Board.from_moves(""), 4).nodes < search(Board.from_moves(""), 4, alphabeta=False).nodes

    done = Board.from_moves("0101010")
    assert search(done, 3).move is None and done.moves == [0, 1, 0, 1, 0, 1, 0]
    print("ai_minimax.py OK")
```

### Task 3: Iterative deepening แบบจำกัดเวลา

**Files:**
- Modify: `ai_minimax.py`

**Interfaces:**
- Consumes: `search` และกลไก recursion ภายในจาก Task 2
- Produces: `iterative_deepening(board: Board, time_limit: float, heuristic=h1, max_depth: int = 42) -> Result`
  - `Result.depth` คือ depth ล่าสุดที่ค้นครบ
  - `Result.nodes` คือ node รวมของทุก depth รวมถึง depth ที่ค้นไม่ครบ

กติกา:
- ค้น alpha-beta ที่ depth 1, 2, ... ไปจนถึง `max_depth` หรือจนกว่าจะหมดเวลา
- depth 1 ต้องค้นจนจบเสมอ ไม่ว่าจะเหลือเวลาเท่าไร
- ตั้งแต่ depth 2 ขึ้นไป ให้เช็ก `time.perf_counter() > deadline` ทุก node แล้ว `raise` exception ภายใน แล้วจับไว้ที่ชั้นนอก `try/finally` ใน recursion จะถอนหมากคืนให้กระดานกลับเป็นเหมือนเดิม
- ถ้าเจอคะแนน `abs(score) >= WIN_SCORE` ให้หยุดทันที เพราะรู้ผลแพ้ชนะแล้ว
- ถ้ากระดานจบเกมแล้ว ให้คืน `move=None`
