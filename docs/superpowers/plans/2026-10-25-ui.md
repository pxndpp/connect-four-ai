# Game UI (รอบ 3) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** ทำหน้าจอเกม Pygame ที่คนเล่นกับ AI ได้ เลือกสีที่จะถือ (แดงหรือเหลือง) และระดับความยาก 3 ระดับได้ และมีแถบข้างจอแสดงจำนวน node, เวลา และ depth ของตาที่ AI เพิ่งเดิน

**Architecture:** แยก logic ออกจากการวาดจอ
- `Game` เป็นคลาสธรรมดาที่ไม่ import pygame จึงทดสอบได้โดยไม่ต้องเปิดหน้าต่าง
- `ui.py` ทำแค่สามอย่าง คือวาดจอ รับเมาส์/คีย์บอร์ด และทำแอนิเมชัน
- การสุ่มเมื่อคะแนนเท่ากันทำใน `ai_minimax.py` ผ่านพารามิเตอร์ `rng` ถ้าไม่ส่ง `rng` มา การทดลองจะได้ผลเหมือนเดิม

**Tech Stack:** Python 3.14, **pygame-ce 2.5.8** (pygame ตัวเดิมยังไม่มี wheel สำหรับ 3.14 ส่วน pygame-ce เป็น fork ที่ใช้ `import pygame` ได้เหมือนเดิม)

**Spec:** `connect-four-project-summary.md` (ส่วนที่ 1: "ระดับความยากใน UI", "สิ่งที่ผู้ชมเห็นใน demo") และ `GLOSSARY.md`
ทำต่อจาก `docs/superpowers/plans/2026-10-25-ai-experiments.md` เพราะทั้งสองแผนแก้ `ai_minimax.py`

## Global Constraints

- **ระดับความยาก:**

  | ระดับ | การค้น |
  |---|---|
  | `easy` | `search` depth 2 |
  | `medium` | `search` depth 4 |
  | `hard` | `iterative_deepening` เวลา 1.0 วินาที |

- **ค่าเริ่มต้น:** คนถือแดง ระดับ `medium`
- **กฎเกม:** แดงเดินก่อนเสมอ ถ้าคนถือเหลือง AI จะเดินตาแรกทันที
- **การสุ่มเมื่อคะแนนเท่ากัน:** ใช้เฉพาะใน UI ส่วนการทดลองยังเลือกช่องที่ใกล้กลางที่สุดเหมือนเดิม
- **thread:** ไม่ใช้ ก่อนเรียก AI ให้วาดเฟรมที่มีข้อความ "AI thinking..." หนึ่งเฟรมก่อน
- **ข้อความบนจอเป็นภาษาอังกฤษ:** ฟอนต์เริ่มต้นของ pygame ไม่มีตัวอักษรไทย และเครื่องที่ใช้พรีเซนต์อาจไม่มีฟอนต์ไทยให้ใช้
- **ปุ่มลัด:** `1` / `2` / `3` เลือกระดับความยาก, `S` สลับสีที่คนถือและเริ่มเกมใหม่, `N` เริ่มเกมใหม่, `Esc` ออกจากเกม
- **ปุ่มบนแถบข้างจอ:** ใช้เมาส์คลิกได้ ทำงานเหมือนปุ่มลัดข้างบน
- **ขนาดหน้าต่าง:**
  - ช่องละ 90 px กระดานกว้าง 630 px
  - แถบด้านบนสูง 90 px สำหรับหมากโปร่งแสงที่ลอยรอลง
  - แถบข้างจอกว้าง 280 px
  - หน้าต่างรวม 910 × 630 px
- การทดสอบใช้ `assert` ใน `_self_check()` ไม่ใช้ pytest ส่วนการวาดจอใช้ smoke test ด้วย `SDL_VIDEODRIVER=dummy`

## Review Focus

1. **คลิกตอนที่ยังไม่ใช่ตาของคน หรือตอนเกมจบแล้ว:** ต้องไม่มีอะไรเกิดขึ้น (ทดสอบใน Task 2)
2. **คลิกคอลัมน์ที่เต็ม หรือคลิกนอกกระดาน (ในแถบข้างจอ):** ต้องไม่ลงหมากและไม่ crash (ทดสอบใน Task 2)

   - `S` ต้องเริ่มเกมใหม่เสมอ ไม่สลับสีกลางกระดาน
   - เปลี่ยนระดับกลางเกมได้ และมีผลตั้งแต่ตาถัดไปของ AI

   (ทดสอบใน Task 2)
4. **AI ชนะหรือเกมเสมอ:** ต้องแสดงแถบบอกผล และ AI ต้องไม่เดินต่อ (ทดสอบใน Task 2)
5. **ระดับ `hard` ในช่วงกลางเกม:** จอต้องไม่ค้างเกินราว 1.2 วินาที (ตรวจด้วยตาใน Task 4)

### Task 1: สุ่มเมื่อคะแนนเท่ากัน (`rng`)

**Files:**
- Modify: `ai_minimax.py`

**Interfaces:**
- Produces:
  - `search(board, depth, alphabeta=True, heuristic=h1, rng: random.Random | None = None) -> Result`
  - `iterative_deepening(board, time_limit, heuristic=h1, max_depth=42, rng: random.Random | None = None) -> Result`

กติกา:
- ถ้า `rng is None` ให้ทำงานแบบเดิมทุกอย่าง ทั้งคอลัมน์ที่เลือก คะแนน และจำนวน node
- ถ้าส่ง `rng` มา ที่ root ให้ค้นลูกแต่ละตัวด้วย `alpha = best - 1` แทน `alpha = best` เพราะคะแนนเป็นจำนวนเต็ม วิธีนี้ทำให้ลูกที่ได้คะแนนเท่ากับ `best` คืนค่าที่แท้จริง ไม่ใช่แค่ขอบเขตบน จากนั้นเก็บทุกคอลัมน์ที่ได้คะแนน `== best` แล้วเลือกหนึ่งตัวด้วย `rng.choice`


### Task 2: Game controller (ไม่ใช้ pygame)

**Files:**
- Create: `game_controller.py`

**Interfaces:**
- Consumes: `Board`, `RED`, `YELLOW` (game), `search`, `iterative_deepening` (ai_minimax)
- Produces (`game_controller.py`):
  - `DIFFICULTIES = {"easy": ("depth", 2), "medium": ("depth", 4), "hard": ("time", 1.0)}`
  - `BOARD_X0, CELL = 0, 90`
  - `col_from_x(x: int) -> int | None`: คืนคอลัมน์ 0-6 ถ้า `0 <= x < 630` ไม่เช่นนั้นคืน `None`
  - `class MoveStats(NamedTuple)`: `col: int`, `nodes: int`, `ms: float`, `depth: int`
  - `class Game`
    - `__init__(self, human_player: int = RED, difficulty: str = "medium", seed: int | None = None)`
    - attribute: `board`, `human_player`, `difficulty`, `last_ai: MoveStats | None`
    - `is_over() -> bool`
    - `is_human_turn() -> bool`: เป็น `True` ก็ต่อเมื่อเกมยังไม่จบและ `board.turn == human_player`
    - `human_move(col: int) -> bool`: คืน `False` และไม่เปลี่ยนอะไรเลย ถ้ายังไม่ใช่ตาของคน, เกมจบแล้ว หรือคอลัมน์เต็ม
    - `ai_move() -> MoveStats`: ใช้ `rng` ของ `Game` เดินแล้วบันทึกลง `last_ai`
      - `raise RuntimeError` ถ้าเป็นตาของคนหรือเกมจบแล้ว
      - ระดับ `easy` / `medium` ใช้ `MoveStats.depth` เป็น depth ที่ตั้งไว้ ส่วน `hard` ใช้ `Result.depth`
    - `set_difficulty(name: str) -> None`: ถ้าชื่อไม่อยู่ใน `DIFFICULTIES` ให้ `raise ValueError`
    - `new_game(human_player: int | None = None) -> None`: ถ้าไม่ระบุ `human_player` ให้ใช้สีเดิม และล้าง `last_ai`
    - `switch_side() -> None`: สลับสีที่คนถือแล้วเรียก `new_game`
    - `status_text() -> str`: คืนหนึ่งในข้อความ `"Your turn"`, `"AI thinking..."`, `"You win!"`, `"AI wins"`, `"Draw"`

- [ ] **Step 1: เขียน self-check ที่ยังไม่ผ่านใน `game_controller.py`**

```python
def _self_check():
    assert col_from_x(0) == 0 and col_from_x(629) == 6 and col_from_x(630) is None and col_from_x(-1) is None

    g = Game(seed=0)
    assert g.is_human_turn() and g.status_text() == "Your turn"
    assert g.human_move(3) and not g.is_human_turn()
    assert not g.human_move(2)                                # ยังเป็นตาของ AI
    s = g.ai_move()
    assert s.col in range(7) and s.nodes > 0 and s.depth == 4 and g.last_ai == s and len(g.board.moves) == 2
    try:
        g.ai_move()
        assert False
    except RuntimeError:
        pass

    g = Game(human_player=YELLOW, difficulty="easy", seed=0)
    assert not g.is_human_turn() and g.status_text() == "AI thinking..."
    g.ai_move()
    assert g.is_human_turn()

    g = Game(seed=0)
    for c in "001122":
        g.board.drop(int(c))
    assert g.human_move(3) and g.is_over() and g.status_text() == "You win!"
    assert not g.human_move(4) and not g.is_human_turn()

    g = Game(seed=0)
    for c in "000000":
        g.board.drop(int(c))
    assert not g.human_move(0) and len(g.board.moves) == 6   # คอลัมน์เต็ม

    g = Game(seed=0)
    g.human_move(3)
    g.set_difficulty("hard")
    assert g.ai_move().depth >= 1
    g.switch_side()
    assert g.human_player == YELLOW and g.board.moves == [] and g.last_ai is None
    try:
        g.set_difficulty("insane")
        assert False
    except ValueError:
        pass

    g = Game(seed=0)
    for c in "0213465" * 6:
        g.board.drop(int(c))
    assert g.is_over() and g.status_text() == "Draw"
    print("game_controller.py OK")
```

### Task 3: หน้าจอ Pygame

**Files:**
- Create: `ui.py`
- Modify: `requirements.txt` (เพิ่มบรรทัด `pygame-ce==2.5.8`)

**Interfaces:**
- Consumes: `Game`, `col_from_x`, `DIFFICULTIES`, `CELL` (game_controller)
- Produces:
  - `main(smoke: bool = False) -> None`
  - `python ui.py` สำหรับเล่นจริง
  - `python ui.py --smoke` วาดแต่ละสถานะหนึ่งเฟรมแล้วออก (exit 0)

สิ่งที่ต้องวาด:
- **กระดาน:** พื้นสีน้ำเงิน ช่องว่างเป็นวงกลมสีเข้ม แถว 0 ของ `grid` อยู่ล่างสุดของจอ
- **หมากโปร่งแสง:** ลอยเหนือคอลัมน์ที่เมาส์ชี้ แสดงเฉพาะตอนที่เป็นตาของคน
- **แอนิเมชันหมากตก:** ประมาณ 0.25 วินาทีต่อการตก 6 แถว ใช้ความเร่งคงที่ ทั้งตาของคนและตาของ AI ระหว่างแอนิเมชันไม่รับการคลิก
- **แถบข้างจอ:**
  - `status_text()`
  - สีที่คนถือ
  - ปุ่มระดับความยาก 3 ปุ่ม (ไฮไลต์ปุ่มที่เลือกอยู่)
  - ปุ่ม `Switch side (S)` และ `New game (N)`
  - สถิติตาล่าสุดของ AI: `Column`, `Nodes`, `Time (ms)`, `Depth`
- **เมื่อเกมจบ:** แถบบอกผลกลางกระดานแบบโปร่งแสง

ลำดับในหนึ่งรอบของ loop:
1. รับ event
2. ถ้าเป็นตาของ AI และไม่มีแอนิเมชันค้างอยู่ ให้วาดเฟรม "AI thinking..." แล้ว `pygame.display.flip()` ก่อน
3. เรียก `ai_move()`
4. เริ่มแอนิเมชันของหมากที่ AI ลง
